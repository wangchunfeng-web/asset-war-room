設定與公開發布中心

專屬 Cloudflare Worker 報價代理

本版本預設綁定您的專屬 Worker，同時負責抓取台美股個股與三大市場大盤指數（^TWII / ^SOX / ^IXIC）；若線路異常會自動切換 3 組公開 CORS 備援代理。

即時美元匯率 (USD / TWD)

預設自動從 open.er-api.com 抓取最新市場匯率（備援 Yahoo Finance TWD=X），亦可手動微調覆寫。

GitHub `portfolio.json` 公開發布與管理

訪客開啟網頁時會自動依序讀取 Cloudflare KV → 同目錄 portfolio.json → 內建台美股範例。若匯入含舊版加密貨幣或現金的 JSON，系統會自動過濾保留純台美股標的。

發布至 wangchunfeng-web/asset-war-room 步驟

1
開啟管理員編輯持股

點右上角 管理員（或開啟 ?admin=1）增刪修改台美股持股，系統會立即自動抓價並重算總覽。

2
匯出 portfolio.json

點擊上方 匯出 portfolio.json，確認檔名為小寫 portfolio.json（勿帶 (1) 後綴）。

3
上傳至 GitHub 根目錄

前往 wangchunfeng-web/asset-war-room → Add file → Upload files 覆蓋上傳，約 1–2 分鐘全球生效！

Cloudflare KV 雲端零延遲同步（免上傳 GitHub）

升級您的 stock-proxy Worker 並綁定免費 KV 資料庫後，您在網頁上修改持股就能秒速發布至雲端，所有訪客重整立即看到最新台美股資產。

升級版 Cloudflare Worker 程式碼（Yahoo 報價代理 + KV 公開讀寫）

Cloudflare 後台設定：KV Namespace 綁定變數名稱 PORTFOLIO_KV，並於 Settings → Variables and Secrets 新增 Secret ADMIN_TOKEN。
